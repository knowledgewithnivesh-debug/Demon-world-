# DEMON: Soul World

A mobile-first 3D fantasy adventure game.

## Vision
Explore a mysterious world, fight fantasy enemies,
discover companions, complete quests, and grow stronger.

## Planned Features
- 3D exploration
- Mobile touch controls
- Player character and companion pets
- Quests, XP, and progression
- Fantasy environments and enemies
- Responsive browser gameplay

## Technology
- HTML5
- CSS3
- JavaScript
- Three.js for 3D graphics

## Development
Built on Android using Acode and GitHub.

## Security
Never commit passwords or private API keys.
